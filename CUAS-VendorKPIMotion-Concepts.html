Concepts only — not wired into the Learn More page yet. Three directions for animating a vendor's five KPI scores, each auto-cycling CUAS Vendor 1 → 2 → 3 on a loop. Pick one (or mix elements) before it gets built into Card 4.
Concept 1

Animated Horizontal Bars

Five labeled bars, one per KPI. Bar length and the number both animate when the vendor changes — reads fast, works at small sizes, easiest to scan KPI-by-KPI.

Concept 2

Arc Gauge Cluster

Five dial-style gauges in a row, each arc sweeping to the new value. Closest to a cockpit/dashboard feel — more visual weight per KPI, better for a shorter hold time since it reads as a cluster rather than a list.

Concept 3

Vertical Column Chart

Classic bar-chart columns rising and falling between vendors. Most familiar chart form, reads well as a single glance "shape" per vendor rather than five separate data points.
